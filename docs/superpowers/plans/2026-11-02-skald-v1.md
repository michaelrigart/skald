# Skald v1 Implementation Plan

**Status:** In progress (branch `feat/skald-v1`). Awaiting Codex's plan review.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Skald, a macOS 27 menu bar app that checks spelling and grammar in English, Dutch
and French as the user types in other apps, using Apple's on-device model, plus a panel that
fixes or rewrites a selection on This Mac, the Mac Studio or Claude.

**Architecture:**
- **`Packages/SkaldCore`** holds every rule: text offsets, the token diff, the evaluation scorer,
  paragraphs, issues, the edit guard, the check scheduler, the check pipeline, engine routing,
  prompts, settings storage and the remote engine clients. It declares the platform interfaces.
  It imports Foundation and Observation only.
- **`Packages/SkaldPlatform27`** implements those interfaces for macOS 27: Foundation Models,
  Natural Language, `NSSpellChecker`, Accessibility, and the evaluation runner `skald-eval`.
- **The app target, `Skald`,** is a thin AppKit and SwiftUI shell with the composition root.

**Tech Stack:** Swift 6.4 (Xcode 27.2, macOS 27.2 SDK), Swift Testing, Foundation Models,
Natural Language, AppKit (`NSSpellChecker`, `NSStatusItem`, `NSPanel`), Accessibility
(`AXUIElement`), SwiftUI, ServiceManagement, Security (Keychain), XcodeGen pinned in `mise.toml`.

**Spec:** `docs/superpowers/specs/2026-11-02-skald-design.md`. Read it before any task. "Measured
on macOS 27.2" holds the platform facts this plan relies on; the edit guard's outcome table is a
contract.

## Global Constraints

- **Platform and language:**
  - Deployment target macOS 27.0, Swift 6 language mode, complete strict concurrency checking.
  - Packages use `// swift-tools-version: 6.4` and `.macOS(.v27)`; if `.v27` is not defined,
    `.macOS("27.0")`.
- **Bundle and signing:** bundle identifier `com.michaelrigart.skald`; Info.plist `LSUIElement`
  YES, `CFBundleDisplayName` Skald, version `0.1.0`, build `1`; not sandboxed; Hardened Runtime on;
  ad-hoc signing (`CODE_SIGN_IDENTITY "-"`, `CODE_SIGN_STYLE Manual`).
- **Core imports:** `SkaldCore` imports only `Foundation` and `Observation`. No AppKit, SwiftUI,
  ApplicationServices, FoundationModels, NaturalLanguage or `os`, and no `#available`.
- **Text offsets** are UTF-16 code units everywhere (`TextRange`), matching Accessibility's
  `CFRange` and `NSString`. Never index a Swift `String` by `Character` count for a range.
- **Never:** write user text to disk or logs (the probe's synthetic seed outputs are the only text
  Skald writes); post synthetic keyboard or mouse events; read a
  secure text field (`AXSecureTextField` role or subrole); send text to a remote engine except
  through the panel's routing rules; download or compile a model.
- **Values:**
  - typing pause before a check: 700 ms;
  - paragraph chunk limit for a model request: 1,200 UTF-16 units, split at sentence ends;
  - field read window: fields over 20,000 UTF-16 units are read as 5,000 units either side of
    the caret;
  - language: only `en`, `nl`, `fr`; a hypothesis must reach 0.6, and paragraphs under 20 UTF-16
    units inherit the field's last confident language;
  - edit guard: a result changing more than 40% of the paragraph's tokens is discarded (starting
    value; Task 12 may tune it on the tuning part only);
  - timeouts: Apple engine 10 s, remote engines 30 s, Accessibility messaging 0.25 s per call;
  - remembered checked paragraphs: the newest 200.
- **Model requests:** greedy sampling; one fresh session per request; instructions from
  `Prompts` only (Task 7).
- **Claude request:** `POST https://api.anthropic.com/v1/messages`, headers `x-api-key`,
  `anthropic-version: 2026-10-21`, `anthropic-beta: server-side-fallback-2026-07-01`,
  `content-type: application/json`; body `model` (default `claude-opus-5-5`), `max_tokens` 4096,
  `fallbacks: "default"`, `system`, one `user` message, `output_config: {effort: "low"}`. No
  `temperature`, no `thinking`.
- **Files:** `~/Library/Application Support/com.michaelrigart.skald/settings.json` (version 1);
  a corrupt file is moved to `settings.corrupt.json`. The Claude key lives in the Keychain,
  service `com.michaelrigart.skald`, account `claude-api-key`.
- **Default-off apps:** `com.mitchellh.ghostty`, `com.apple.Terminal`, `com.googlecode.iterm2`,
  `com.microsoft.VSCode`, `com.apple.dt.Xcode`, `dev.zed.Zed`, `com.1password.1password`,
  `com.bitwarden.desktop`, and Skald itself.
- **Coordination:** no `Task.sleep`, `asyncAfter` or timers to let things settle. The typing
  pause runs on an injected `Clock`. Blocking Accessibility and spell-checker calls run on
  dedicated serial `DispatchQueue`s, never on the main actor or the cooperative pool.
- **Unsafe annotations.** `@unchecked Sendable` and `nonisolated(unsafe)` each need a `// reason:`
  comment on the same line.
- **Logging:** `Logger(subsystem: "com.michaelrigart.skald", category: …)` in the platform and app
  only. Events, timings, engine kinds and failure kinds at `.notice`; never text, never the
  never-touch list, never the key. A system error's description is logged `.private` and replaced
  by a fixed failure kind.
- **Build and test outside the Claude sandbox,** prefixed with
  `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`. Don't change `xcode-select`. The
  spell server and Foundation Models are unreachable inside the sandbox.
- **Parallel tasks** pass their own build paths: `--scratch-path build/spm-task<N>` for `swift
  test`, `-derivedDataPath build/dd-task<N>` for `xcodebuild`.
- **Generated, never committed:** `Skald.xcodeproj/`, `build/`, `.build/`, `.superpowers/`.
- **Copy:** English only. Public files carry no machine details and no real company names.

## Review Focus

1. **Emoji, accented and combined characters before a flagged word** shift UTF-16 offsets away
   from `Character` offsets; underlines and replacements must still hit the exact word. Tested
   in Tasks 3 and 4 (a paragraph starting "👍🏽 Ik heb … gedownloaded").
2. **The model wraps its answer** in quotes, a "Corrected text:" preamble, a code fence or an empty
   `<think></think>` block. Wrappers the input didn't have are stripped; anything else that
   changes too much is discarded whole, never offered as edits. Tested in Tasks 5 and 7.
3. **Focus moves to another field holding the same text** (two identical reply boxes). Issues
   belong to their field and never carry over. Tested in Task 4.
4. **Apple Intelligence turns off, or thermal state rises, mid-check.** The running check ends as
   cancelled, spelling flags stay, and no confirmation request is sent. Tested in Task 14.
5. **A very long field** (a 60,000-character email thread): only the window around the caret is
   read and checked, and no full-field read repeats on each keystroke. Tested in Task 4 (window
   arithmetic), Task 6 (one read per pause), Task 13 (ranged reads and their fallback) and Task 14
   (one read for ten edits on a 60,000-unit field).

  - `public struct Edit: Hashable, Sendable { public let tokenSpan: Range<Int>; public let
    replacementTokens: [String]; public let range: TextRange; public let original: String; public

  - `public enum TextDiff { public static func edits(from original: String, to revised: String)
    -> [Edit] }`;
  - `public struct EvalCase: Codable, Sendable { id, lang: Language, text, ref: String }`,
    `public struct EvalOutput: Codable, Sendable { id, lang: Language, output: String?, error:

    cleanFlagged, cleanTotal: Int; precision, recall, f05: Double; p50Ms, p90Ms: Double }`;
  - `public enum EvalScorer { static func score(_ cases: [EvalCase], _ outputs: [EvalOutput]) ->
    EvalScore; static func byLanguage(_:_:) -> [Language: EvalScore]; static func loadJSONL<T:
    Decodable>(_ url: URL) throws -> [T] }`.

The tokenizer is the spike's: matches of `\w+|[^\w\s]` with Unicode word characters, found with
`NSRegularExpression` so ranges are UTF-16. The diff is a port of Python's
`difflib.SequenceMatcher(autojunk=False).get_opcodes()` over token texts (longest matching block,
recursively left and right), so its edits equal the spike scorer's. For each non-equal opcode:
`range` runs from the first changed original token's start to the last one's end (zero length at
the next token's start for an insertion); `original` and `replacement` are the trimmed texts;
`spliceRange` runs from the end of the preceding equal token (or 0) to the start of the following
equal token (or the end), and `spliceText` is the revised string's text between the same two
equal tokens. Applying one edit is `original[..<spliceRange] + spliceText + original[spliceRange.end...]`.
`p90Ms` uses the spike's index `sorted[Int(count * 0.9) - 1]`.

### Task 6: The check scheduler

**Depends on:** Task 4 · **Tier:** sp-standard

**Files:**
- Create: `Packages/SkaldCore/Sources/SkaldCore/Scheduler/CheckScheduler.swift`
- Create: `Packages/SkaldCore/Tests/SkaldCoreTests/CheckSchedulerTests.swift`

**Interfaces:**
- Consumes: `FieldEvent`, `FieldID`, `FieldSnapshot`, `Paragraph`, `Paragraphs`, `ParagraphKey`,
  `ParagraphKeys` (Task 4).
- Produces: a pure state machine
  `public struct CheckScheduler: Sendable { init(pause: Duration = .milliseconds(700), remember:
  Int = 200); mutating func handle(_ event: SchedulerEvent, at now: Duration) -> [SchedulerEffect]
  }` (`now` is the time elapsed since an origin the caller keeps) with
  `public enum SchedulerEvent: Sendable { case field(FieldEvent), timerFired, snapshot(FieldSnapshot),
  modelFinished(ParagraphKey), modelFailed(ParagraphKey), paused, resumed, recheck }` and
  `public enum SchedulerEffect: Equatable, Sendable { case armTimer(deadline: Duration),
  disarmTimer, read(FieldID), suspendIssues(FieldID), revalidate(FieldSnapshot), clearIssues,
  checkSpelling(ParagraphKey, Paragraph), checkModel(ParagraphKey, Paragraph), cancelModel }`.

Rules:
- **Reading.** `field(.focused(f))` disarms, cancels the running model check, clears the model
  queue, and for a non-nil `f` arms the timer. `field(.edited(f))` for the current field emits
  `suspendIssues(f)` and arms the timer for `now + pause`; `field(.caretMoved(f))` arms it.
  `timerFired` emits exactly one `read(currentField)`. Events never read text; reads happen only
  on `timerFired`, so a burst of edits costs one read.
- **Checking.** `snapshot(s)` for the current field emits `revalidate(s)`, then takes the caret's
  paragraph, its chunks and their keys (`ParagraphKeys`). Each chunk key not yet spell-checked emits
  `checkSpelling`. The chunk keys not in the remembered set form the model queue, in order. If the
  running model check's key is the queue's head, it keeps running; otherwise emit `cancelModel`
  (when one runs) and `checkModel` for the head.
- **Advancing.** `modelFinished(k)` remembers `k` (newest 200) and emits `checkModel` for the next
  queued chunk; `modelFailed(k)` advances the same way without remembering `k`. Only a new
  `snapshot` with a different queue cancels a running check.
- **Pausing.** `paused` emits `disarmTimer`, `cancelModel` (when one runs) and `clearIssues`, and
  while paused every event except `resumed` and `field(.focused)` (which only tracks the field) is
  ignored. `resumed` arms the timer. `recheck` forgets the remembered and spell-checked keys,
  cancels the running check and arms the timer.

- [ ] **Step 1: Write the tests**, each with exact effect lists and durations from 0:
  - edit at 0 arms 700 ms and suspends issues; edit at 300 ms re-arms 1,000 ms; ten edits then one
    `timerFired` emit one `read`;
  - a snapshot emits `revalidate`, then spelling and model for the caret paragraph; the same
    unchanged paragraph after `modelFinished` emits nothing on the next snapshot;
  - a three-chunk paragraph emits three `checkSpelling` and `checkModel` for chunk 1 only;
    `modelFinished(chunk 1)` emits `checkModel(chunk 2)`, then chunk 3; `modelFailed(chunk 2)`
    also advances to chunk 3 without remembering chunk 2;
  - a snapshot with a different caret paragraph while chunk 1 runs emits `cancelModel` then the new
    `checkModel`;
  - in "They is ready\nok\nThey is ready", after occurrence 0 is checked, a snapshot with the caret
    in occurrence 1 emits `checkModel` for occurrence 1;
  - `paused` emits `disarmTimer`, `cancelModel`, `clearIssues`, and edits while paused emit nothing;
  - `recheck` re-checks a remembered paragraph on the next snapshot.

### Task 14: The check pipeline

**Depends on:** Tasks 4, 5, 6, 7, 8 · **Tier:** sp-standard

**Files:**
- Create: `Packages/SkaldCore/Sources/SkaldCore/Pipeline/CheckPipeline.swift`
- Create: `Packages/SkaldCore/Tests/SkaldCoreTests/CheckPipelineTests.swift`,
  `Support/FakeTextAccess.swift`, `Support/FakeEngine.swift`, `Support/FakeSpelling.swift`,
  `Support/FakeLanguageDetector.swift`, `Support/TestClock.swift`

**Interfaces:**
- Consumes: Tasks 4–8, including `GatedConfirmer` (Task 7).
- Produces: `public actor CheckPipeline` with
  `init(access: any TextAccess, apple: any Engine, spelling: any SpellingChecking, detector: any
  LanguageDetecting, oracle: any WordOracle, confirmer: (any EditConfirming)?, clock: any
  Clock<Duration>, settings: Settings, router: EngineRouter)`, `func start()` (consumes
  `access.events`), `func setPaused(_ p: Bool)`, `func update(settings: Settings, router:
  EngineRouter)`, `var issues: AsyncStream<IssueSnapshot>` with `public struct IssueSnapshot:
  Sendable, Equatable { field: FieldID?; issues: [Issue] }`, `func accept(_ id: UUID) async ->
  ReplaceOutcome`, `func ignore(_ id: UUID)`, and `func neverFlag(_ id: UUID) -> String?`.

Behaviour:
- **Driving.** Field events and timer fires go to `CheckScheduler` with the clock's elapsed time
  since `start()`; `read` effects call `access.snapshot(of:)` once and feed the result back as
  `snapshot`.
- **Route first.** For each paragraph to check, the pipeline detects its language (keeping the
  field's last confident one) and asks the current router `typing(language)` before anything runs:
  `.off` → no spelling and no model call, and the paragraph's issues are cleared; `.spellingOnly` →
  spelling only; `.model` → spelling, then the model. The route is asked again right before each
  model request.
- **Model results** go through `OutputCleaner`, `judgeWhole` (with the detector's language of the
  output), then `resolve` with the oracle and a `GatedConfirmer` whose gate is "the current
  router's `typing(language)` is `.model`". Spelling flags go through `resolve` with no confirmer.
- **Live changes.** `update(settings:router:)` replaces the guard (new never-touch set), removes
  issues touching never-touch words, and, when the current paragraph's route is no longer
  `.model`, cancels the running model check; when the typing or model-check switches changed it
  sends `recheck`. An engine failure `unavailable` treats the route as `.spellingOnly` until the
  next `update`.
- **Never flag.** `neverFlag` returns the issue's word and removes every issue on that word at once
  (`IssueTracker.removeAll(word:)`); the caller stores it in settings and calls `update`.
- **Accept** calls `access.replace` with the issue's `spliceRange` and `spliceText` shifted to
  field coordinates and `ExpectedText(range: paragraph.range, text: paragraph.text)`, then drops the
  issue whatever the outcome.

  - text changed during the model check drops its result;
  - `typingChecks[nl] = false` → no spelling and no model call for a Dutch paragraph;
  - `update` with an unavailable-Apple router while a model check is suspended cancels it, keeps
    the spelling issues, and never calls the confirmer;
  - after `neverFlag` on "Talos" and `update` with "Talos" in the never-touch list, the next check
    offers no edit on "Talos";
  - a three-chunk paragraph's model checks run one after another and all three results arrive;
